# Quirky Bar Deckbuilding Game 🃏🍹

This is a **deckbuilding web game** where you manage a bar, collect various components, and keep a picky customer base happy. Draw cards, dig through the discard pile, and pay close attention to everyone’s preferences. Win over enough customers and you win; fail to keep them happy and you lose.  

The game features **lots of silly drawings** and a **quirky user interface**, reflecting a playful and experimental approach to frontend development. It was created **prior to the AI boom** and before my time as a CS student, showcasing my early creativity and problem-solving skills.
